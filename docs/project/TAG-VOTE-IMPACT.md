# 衣物与推荐标签投票结果及工作影响

记录日期为 2026-11-16。06 正在同步修改《网页功能概述》。本记录用于让各轮负责人核对已确定的方向和受影响接口。

## 投票结果

1. 衣物的风格标签采用固定标签集，数量超过 6 个。
2. 推荐页「本次喜好」使用一个开关，提供文字和图片两种输入方式。AI 识别出的标签自动展示，用户可以修改或删除。
3. 衣物上传识别加入场景标签。风格和场景组成超过 9 个基础标签，其中风格超过 6 个，场景超过 3 个。允许 AI 输出「其他」并记录，后续开放用户自定义添加。
4. 推荐页场景增加并细化，投票给出的例子包括运动健身、户外、约会和朋友聚会。

风格与场景的具体固定清单、「其他」保存哪些原始内容、用户自定义的开放时机与交互，等待新版《网页功能概述》明确。衣物场景标签和推荐时选择的本次场景分别属于衣物资料和本次条件，具体对应方式以新概述和推荐规则为准。

## 人工验收重点

- 旧衣物在迁移后仍能读取，风格和场景字段的转换、缺省及「其他」处理均有测试。
- 单件和批量衣物识别可展示风格／场景标签，用户确认后的内容才用于保存。
- 本次喜好开启时可用文字、图片或两者。AI 标签可修改、删除，提交后的条件符合用户最终确认内容。
- 喜好开关关闭时保留草稿，生成时不读取该条件。修改草稿不自动应用，也不清除本轮状态。
- 推荐场景按新版概述提供可选和自填方式。所用条件进入依据，未启用或未提交条件不进入推荐。
- 持续检查三条铁律：点击「生成穿搭」并成功才开启新轮，单次反馈在同一轮有效，首页与推荐页调整独立。

各负责人根据新版概述更新自己的接口、测试及交接。若投票解释或与既有记忆规则有冲突，先列明问题和影响，再确认具体规则。
