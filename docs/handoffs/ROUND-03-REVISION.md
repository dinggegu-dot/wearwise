## 白底模型比较与配置

OpenRouter 官方 Image API 用 `POST /api/v1/images`、`input_references` 传原图，返回 `data[0].b64_json` 图片。当前选定 `bytedance-seed/seedream-5-0-flash`，四张真实图片均成功返回；实测每张费用 $0.018，逐张串行耗时 17.34–18.49 秒。价格可能变化，以每次响应的 `usage.cost` 为准。以后可只修改 `OPENROUTER_BACKGROUND_MODEL` 切换其他兼容模型。

试验时使用用户提供的四张新图片；逐张保存输出，记录模型 ID、耗时、响应头中的实际费用、尺寸、背景洁白程度、颜色／图案／轮廓是否被改动。任何会改变衣物真实细节的模型不得直接作为正式白底服务。配置仍是服务端 `.env.local` 的 `OPENROUTER_API_KEY` 和 `OPENROUTER_BACKGROUND_MODEL`；不把密钥或图片内容写入日志。

官方依据：[Image API 格式](https://openrouter.ai/blog/tutorials/image-generation/)、[图片模型目录](https://openrouter.ai/collections/image-models/)、[Seedream 模型页](https://openrouter.ai/bytedance-seed/seedream-5-0-flash)。
